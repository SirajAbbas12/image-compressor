Image Compressor to 20KB & 50KB
A free online tool to compress JPG, PNG and WEBP images strictly under 20 KB or 50 KB. Made for government application forms, exam portals (SSC, UPSC, Railway) and passport photo uploads.
🔗 Live Demo: https://image-compressor-blond.vercel.app
Features
Strict target size: compress photos or signatures below 20 KB or 50 KB
Formats: JPG, PNG and WEBP input, with JPG / PNG / WEBP output choice
Quality control: adjust quality manually (default 75%)
Live preview: see original size vs. new size and % reduced
100% private: images are processed in your browser using client-side JavaScript canvas rendering. Nothing is uploaded to any server
Free: no sign-up, no installation
Mobile friendly: works on phone and desktop
Supports files up to 50 MB
How to Use
Open the live website
Drop or select your image (JPG, PNG or WEBP)
Choose the target: < 20KB or < 50KB
Pick the output format and adjust quality if needed
Click Download Image
Tech Stack
HTML, CSS, JavaScript (canvas-based client-side compression)
Deployed on Vercel
